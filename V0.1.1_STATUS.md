# Township Offline Save Editor v0.1.1

## Hoàn thành trong bản này

- Phân biệt mGameInfo nhị phân và XML đã giải mã.
- XML đã giải mã mở được ở chế độ chỉ đọc, không còn lỗi do cố lấy content seed.
- Chỉ bật nút tạo save khi nguồn là container nhị phân hợp lệ.
- Giới hạn container tối đa 64 MB và XML giải nén tối đa 32 MB.
- Kiểm tra kích thước LZ4 trước khi cấp phát bộ nhớ.
- Round-trip so sánh với XML đã cắt chính xác đến `</root>`.
- Tăng versionCode lên 2 và versionName lên 0.1.1.

## Kiểm thử đã chạy

- Kotlin parser/change/history: PASS.
- Kotlin syntax check codec/repository bằng API stub LZ4: PASS.
- Golden save thực từ các phase trước vẫn được giữ trong `app/src/test/resources/fixtures`.

## Chưa thể xác nhận trong môi trường hiện tại

- Gradle Android build đầy đủ.
- Cài APK trên LDPlayer.
- UI runtime trên Android.

Nguyên nhân: môi trường hiện tại không có Android SDK, Android Gradle Plugin cache và `gradle-wrapper.jar`.
